# Results

- `intensity_summary.csv` contains the six Fusion-feature scores from the original reported RAVDESS run. These are the values used in the final report and main README.
- `three_corpus_summary.csv` contains the within-corpus speaker-independent comparison of RAVDESS, EMO-DB, and CREMA-D.
- `figures/` contains the three publication-ready figures embedded in the project report.

`notebooks/SER_Intensity_Mismatch_Public.ipynb` performs a separate fixed public rerun and displays its scores next to the original reported values. The two sets are intentionally labeled separately because the original run's exact actor-fold assignment was not archived.

The cross-corpus table is descriptive. It should not be interpreted as a controlled causal comparison because the corpora differ in language, recording conditions, speakers, acting style, and sample size.
